> 不是插件运行期文件，不在 `.toc` 里，不随插件发布。

| 文件 | 用途 |

## 术语表（原主库 glossary.txt 中与本项目相关的条目）

以下术语在本仓库语境下的含义：

| 术语 | 含义 |
|---|---|
| Tabibito Jisho | 旅人辞典，本插件总称，`/jisho` 命令打开 |
| SM-2 | SuperMemo 2 间隔重复算法，用于闪卡复习调度 |
| 闪卡 | flashcard，正面显示问题/假名，背面显示答案/读音 |
| 两段揭示 | 闪卡翻转交互：正面 → 点击 → 读音 → 点击 → 自评按钮 |
| 听音辨字 | 听音频从 4 个选项中选正确假名的复习模式 |
| 认读 | 看假名想读音的复习模式（默认模式） |
| 词典标签页 | `/jisho` 面板的第三个标签，浏览/搜索/筛选 504 个精选日语单词 |
| TJ_LangDB | 本插件唯一的 SavedVariable，词典/复习/手账共用 |
| TJ_ | 本插件命名空间前缀，替代原 BGLAO_Lang* |
| word-gen.js | `tools/` 下读 `word-source.json` 生成 `words.lua` + TTS manifest 的开发期脚本 |
| kana-gen.js | `tools/` 下从 `kana.lua` 读音节清单生成假名音频的开发期脚本 |
| 按需加载 | lazy init，首次调用 `GetData()` 时才构建数据表，不拖慢 `ADDON_LOADED` |

## 约束

- LF、UTF-8 无 BOM，与仓库红线同口径。
- 新增提示词同时更新本 README。
